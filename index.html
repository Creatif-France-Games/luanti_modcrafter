Luanti ModCrafter

Cet outil permet aux non-programmeurs de créer des mods simples pour Luanti en utilisant une interface graphique facile. Le modding dans Luanti est assez simple. Cet éditeur ne peut pas être utilisé pour créer des mobs, ni pour réaliser le mod de vos rêves qui corrige tout dans Minetest. Si vous souhaitez créer autre chose qu’un bloc décoratif, vous devez apprendre à modder Luanti correctement, en utilisant Lua.

Facile à utiliser

Cet outil vous donne des instructions simples à chaque étape. Il est conçu pour ceux qui ont peu de connaissances sur les internals de Minetest, et donc adapté aux débutants.

Enregistrer et ouvrir des projets

Pour ouvrir un projet, glissez-déposez le fichier sur la page web. Pour enregistrer un projet, cliquez sur sauvegarder sur la page principale.
